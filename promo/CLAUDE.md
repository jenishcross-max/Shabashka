# Видеостудия Шабашки

Эта папка — мастерская роликов для шабашка.com: вертикальные видео 9:16 для
Reels, Threads, TikTok и Shorts. Сессия, открытая здесь, занимается только
роликами: придумать, собрать, показать, отрендерить.

## Кто мы и для кого

- **Шабашка** — работа и подработка в Кыргызстане: вакансии, разовые заказы,
  биржа задач. Сайт — **шабашка.com**, Threads и Instagram — **@shabashka.com_**,
  бот — @shabashka_telegram_bot.
- Зритель — люди из Бишкека, Оша и регионов, которые ищут подработку или
  работников и сидят в общих чатах WhatsApp и Telegram. Язык роликов — русский,
  просто и с юмором, без канцелярита.
- Задача ролика — чтобы досмотрели, переслали другу и зашли на шабашка.com.

## Правила

- Работаем только в `promo/`. `backend/` и `frontend/` не трогаем. Бэкенд
  локально не запускаем: в `backend/.env` лежит боевая база.
- Ничего не публикуем сами: ни в Threads, ни в Instagram, ни в Telegram.
  `npm run publish` (загрузка в HeyGen) — только по прямой просьбе владельца.
  Готовый mp4 показываем владельцу, выкладывает он.
- Коммит делаем, только когда владелец попросит. Пушим только по его слову
  «комит пуш», каждый раз заново.
- Звуковые эффекты — из библиотеки HyperFrames (21 файл с Pixabay, Pixabay Content
  License: можно в рекламе, без указания автора). Лежат в пакете hyperframes
  (`dist/skills/media-use/audio/assets/sfx/`), копируем нужные в `assets/sfx/` ролика
  вместе с `CREDITS.md`; громкость 0,2–0,5, по одному звуку на событие. Самодельные
  звуки из `tools/make_audio.py` владелец 31.10 назвал «странными и не в тему» — для
  эффектов их больше не берём. Музыка: `make_audio.py` или трек Pixabay Music, который
  владелец скачал сам. Шрифты только из `assets/` (Rubik и Golos Text, OFL). Чужие
  треки без лицензии и логотипы не берём.
- Тактика с 31.10.2026 (по цифрам первой недели): главное — реальные заказы с суммами
  и честными плюсами/минусами («5 подработок…», `videos/rabota-vyhodnye` — образец), выход
  вечером. Мемы — редко и только «мем → реальные заказы». Подробнее — в content-calendar.md.
- Трендовые мем-клипы (нарезки из фильмов и шоу с mem.video) брать можно:
  владелец решил так 24.10.2026, потому что алгоритмы лучше крутят узнаваемые
  мемы. Риск по правам он берёт на себя. Клип скачивает владелец сам кнопкой на
  странице мема и кладёт в `promo/clips/`. Сайт массово не качаем. Выбираем
  клипы с речью, без музыки (иначе Instagram глушит звук) и без политиков.
  Что сейчас в тренде: `python tools/mem_radar.py` → `trends/mem-<дата>.md`.
- Мем-ролик из клипа — одной командой: `python tools/meme.py <имя> clips/<клип>.mp4
  --from 0 --to 5.4 --caption "…" --sub "0:…" --end "…" [--key] [--bottom] [--subs-y 880]`
  (подпись-мем сверху, звук клипа, субтитры, финал 2,2 с; `--key` вырезает зелёный фон).
  Точки разреза ищите по паузам в звуке, кадры смотрите после `snapshot`.
- Ставить ролик в расписание бота («🛍 Мои продукты» в @shabashka_telegram_bot,
  через Telegram Web в Chrome владельца) — только по его прямой просьбе. Один
  ролик = один продукт с одним текстом и одним видео (тексты и видео идут по
  кругу, в общем продукте подписи перепутаются). Бот выходит с 10:00 до 21:00;
  у нового продукта первый выход — при ближайшей проверке. После выхода —
  «⏸ Пауза», иначе повторится.
- Имена в переписках выдуманные. Никаких настоящих телефонов, фамилий и
  скриншотов чужих чатов.
- Цифры (зарплаты, сроки) должны быть правдоподобными. Настоящие примеры берите
  со страницы списка на шабашка.com. Карточки вакансий не открывайте: каждое
  открытие пишется в боевую базу как просмотр.

## Как сделать ролик

```bash
node studio/new.mjs <имя-латиницей> [beat|soft|calm]   # из заготовки → videos/<имя>
cd videos/<имя>
npm run check                                           # должно быть «Check passed»
npx --yes hyperframes@0.8.169 snapshot --at 2,6,10 --no-end --describe false
npx --yes hyperframes@0.8.169 render --quality delivery --video-bitrate 12M --output renders/master.mp4
python ../../tools/finish_reel.py renders/master.mp4 renders/<имя>.mp4   # громкость −14 и размер; master потом удалить
```

- Сначала мастер на 12 Мбит/с (без него ролики выходили 0,8 Мбит/с, мелкий текст мылился),
  потом `tools/finish_reel.py`: x264 CRF 18 и loudnorm в два прохода до −14 LUFS. Готовый файл —
  до 15 МБ: бот скачивает видео продукта из Telegram только до 20 МБ, тяжелее — пост уходит
  без ролика, и Instagram его не принимает (7.11 мастер 14 с весил 21,4 МБ).

- Заготовка (`studio/template/index.html`) — рабочий ролик в формате «POV» на
  12,5 секунды: крючок, чат, решение, финал с адресом. Новый ролик — это она
  же с другими текстами, сценами и таймингами.
- Если длина изменилась, поправьте `data-duration` у `#root` и у `#bgm`, а
  музыку пересоберите под новую длину:
  `python tools/make_audio.py videos/<имя>/assets <секунды+1> <настроение>`.
- Редактор в браузере: `npx --yes hyperframes@0.8.169 preview --background` в
  папке ролика, потом откройте http://localhost:3002. Остановить —
  `preview --stop`.
- Кадры после `snapshot` смотрите глазами, прежде чем рендерить.
- Готовый ролик впишите строкой в таблицу в `README.md`.
- Скиллы HyperFrames, на которые ссылается `CLAUDE.md` внутри роликов, не
  установлены. Справка без сети: `npx --yes hyperframes@0.8.169 docs <тема>`
  (`gsap`, `data-attributes`, `rendering`). Ставить скиллы — только с согласия
  владельца.

## Фирменный стиль

- 1080×1920, 30 кадров в секунду, 10–25 секунд.
- Цвета сайта: красный `#f0433e`, тёмный `#241a19`, светлый `#fbf7f6`, фон чата
  `#e9ddd9`.
- Заголовки — Rubik 800–900, текст — Golos Text 400–700. Классы `.h-xl`, `.h-l`,
  `.accent` уже есть в заготовке.
- Поля: сверху 230 px, снизу 300 px (`.pad`). Instagram закрывает низ подписью,
  так что важное туда не ставим.
- В первые полторы секунды — крючок: вопрос, «POV», цифра или узнаваемая
  боль. В конце всегда логотип, **шабашка.com** и @shabashka.com_.
- Анимация только через GSAP `fromTo` на общей паузной ленте. Никаких
  `Math.random()` и `Date.now()`: рендер должен выходить одинаковым.

## Идеи прикольных роликов

1. **POV: ищешь подработку в общем чате.** Одни «доброе утро» и гаражи, а
   вакансий ноль. Готов: `videos/pov-chat`.
2. **Ожидание и реальность.** «Работа мечты» против объявления «срочно,
   оплата — опыт».
3. **Угадай зарплату.** Вакансия, три секунды на догадку, ответ.
4. **Словарь шабашника.** «Срочно» — значит, нужно было вчера. «Дружный
   коллектив» — значит, работать некому. И так далее.
5. **Типы объявлений в чатах.** КАПСЛОК, «пишите в лс», «оплата договорная» —
   и как то же самое выглядит на Шабашке.
6. **Три признака мошенника в вакансии.** Полезный формат, такие сохраняют.
7. **Сколько платят в Бишкеке.** Курьер, официант, грузчик — на одной шкале.
8. **Объявление за 30 секунд.** Как выложить работу на сайте, по шагам.
9. **Работа на выходные.** Три подработки на субботу.
10. **Переписка с мамой.** «Мам, я нашёл работу» — «Где?» — «На Шабашке».
