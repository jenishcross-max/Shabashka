# Биржа услуг на шабашка.com — план реализации

> **For Claude:** Use `${SUPERPOWERS_SKILLS_ROOT}/skills/collaboration/executing-plans/SKILL.md` to implement this plan task-by-task.

**Goal:** Новый раздел «Биржа» на шабашка.com: заказчик описывает задачу, исполнители
откликаются со своей ценой, сроком и описанием услуги, заказчик сравнивает и выбирает
одного — после выбора открывается переписка. Тот же API потом использует Android-приложение.

**Architecture:** Отдельные таблицы `tasks` и `task_offers` (не `orders`: заказы читают бот,
автопостинг, рубрики и sitemap — задача биржи не должна туда утечь). Правила «можно или
нельзя» — чистые функции в `exchange.js`, SQL — в `tasksRepo.js`, HTTP — `routes/tasks.js`
(`/api/tasks`). Жалобы, журнал модерации и переписка переиспользуются через
`listing_type = 'task' | 'offer'`. Фронтенд — новые страницы в том же Vite-приложении.

**Tech Stack:** Node.js 24, Express 4, Postgres (Supabase), `node:test`, PGlite (Postgres в
WASM — только для тестов), React 18 + React Router 6 (Vite).

**Ограничения проекта:**
- Бэкенд локально НЕ запускать и не запускать скрипты, которые подключают `backend/src`
  с базой (в `backend/.env` боевая база). Только тесты: `cd backend && node --test test/*.test.js`.
- База в тестах — PGlite в памяти процесса через `test/helpers/stub.js`: любой `require`
  настоящего `src/db` там падает.
- Файлы в CRLF (после правок — нормализация скриптом); комментарии по-русски, «зачем», а не «что».
- Коммит и пуш — только по команде владельца «комит пуш». В плане шагов «commit» нет.
- `schema.sql`, `README.md` параллельно правит другая сессия: свои блоки — только в конец файла.

## Решения из обсуждения (2026-10-14/15)

| Вопрос | Решение |
|---|---|
| Бренд и домен | Биржа живёт на шабашка.com, домен шабаш.com пока не нужен |
| Android | Позже, отдельным этапом на этом же API |
| Связь с заказами | Отдельный раздел «Биржа», заказы не меняются |
| Отклик | Цена (обязательно, сом), срок (текст), комментарий; правка и отзыв — пока исполнитель не выбран |
| Выбор | Один исполнитель; отклики целиком видит только заказчик, остальным — число; выбор можно отменить |
| Статусы задачи | `open → assigned → done`, `assigned → open`, `open/assigned → cancelled` |
| Переписка | Только после выбора; выбранному приходит сообщение в «Сообщения» |
| Новые отклики | Заказчик видит их на странице задачи; значок в шапке |
| Отзывы | Позже; сразу — «выполнено задач на бирже» и «на сайте с …» |
| Модерация | Жалобы на задачи (все) и на отклики (заказчик), в `reports` + Telegram |
| Главная | «Биржа» первым пунктом меню + блок наверху главной |
| Оплата через площадку | Нет в первой версии |

```js
// Настоящий Postgres в памяти процесса (PGlite, WASM-сборка) — для тестов, которым
// мало заглушки: атомарный выбор исполнителя и ON CONFLICT проверяются только на
// живом SQL. С боевой базой не связан ничем: данные живут, пока идёт тест.
// Заодно каждый такой тест прогоняет schema.sql целиком — ошибка в нём уронила бы
// db.init() при деплое, то есть весь сайт.
const fs = require('fs');
const path = require('path');

const SCHEMA = path.resolve(__dirname, '..', '..', 'src', 'db', 'schema.sql');

// Тот же интерфейс, что у src/db: query(text, params) → { rows }. Подменять модуль
// надо синхронно, до первого require, а PGlite поднимается асинхронно — поэтому
// каждый запрос сначала дожидается готовой базы.
function memoryDb() {
  const ready = (async () => {
    const { PGlite } = await import('@electric-sql/pglite');
    const pg = new PGlite();
    await pg.exec(fs.readFileSync(SCHEMA, 'utf8'));
    return pg;
  })();
  return {
    ready,
    query: async (text, params) => (await ready).query(text, params),
  };
}

module.exports = { memoryDb };
```

**Step 4: Таблицы** — дописать в конец `backend/src/db/schema.sql`:

```sql
-- Биржа услуг: заказчик описывает задачу, исполнители предлагают цену и срок,
-- заказчик выбирает одного (правила — в exchange.js, запросы — в tasksRepo.js).
-- Отдельно от orders намеренно: заказы читают бот, автопостинг в Threads и
-- Instagram, рубрики и sitemap, и задача биржи, попавшая туда по забытому
-- фильтру, ушла бы в соцсети. Статусы: open → assigned → done; assigned → open
-- (заказчик отменил выбор); open/assigned → cancelled. Исполнитель — это отклик
-- со статусом accepted, отдельной колонки нет: выбор и задача не разойдутся.
CREATE TABLE IF NOT EXISTS tasks (
  id          SERIAL PRIMARY KEY,
  user_id     INTEGER NOT NULL REFERENCES users(id) ON DELETE CASCADE, -- заказчик
  title       TEXT NOT NULL,
  description TEXT NOT NULL,
  category    TEXT NOT NULL,
  city        TEXT NOT NULL,
  address     TEXT,     -- район или ориентир, без точного адреса
  work_format TEXT NOT NULL DEFAULT 'offline', -- online | offline
  budget      INTEGER,  -- ориентир заказчика; NULL — «цену предложат исполнители»
  when_text   TEXT,     -- когда нужно, своими словами: «в субботу утром»
  status      TEXT NOT NULL DEFAULT 'open', -- open | assigned | done | cancelled
  views       INTEGER NOT NULL DEFAULT 0,
  created_at  TIMESTAMPTZ NOT NULL DEFAULT NOW(),
  updated_at  TIMESTAMPTZ NOT NULL DEFAULT NOW()
);

CREATE INDEX IF NOT EXISTS idx_tasks_status ON tasks(status, created_at DESC);
CREATE INDEX IF NOT EXISTS idx_tasks_user ON tasks(user_id);

-- Отклик исполнителя: цена за всю работу, срок и что именно сделает. Один на пару
-- (задача, исполнитель) — правка обновляет его, а не плодит новые. Целиком отклики
-- видит только заказчик: открытые цены превращают биржу в торги на понижение.
-- seen_at — когда заказчик открыл список; по NULL считается значок «новые».
-- Статусы: active | accepted (выбран) | withdrawn (отозвал сам) | dropped
-- (заказчик отменил выбор) | removed (снят модератором).
CREATE TABLE IF NOT EXISTS task_offers (
  id         SERIAL PRIMARY KEY,
  task_id    INTEGER NOT NULL REFERENCES tasks(id) ON DELETE CASCADE,
  user_id    INTEGER NOT NULL REFERENCES users(id) ON DELETE CASCADE, -- исполнитель
  price      INTEGER NOT NULL,
  term       TEXT NOT NULL,
  comment    TEXT NOT NULL,
  status     TEXT NOT NULL DEFAULT 'active',
  seen_at    TIMESTAMPTZ,
  created_at TIMESTAMPTZ NOT NULL DEFAULT NOW(),
  updated_at TIMESTAMPTZ NOT NULL DEFAULT NOW(),
  UNIQUE (task_id, user_id)
);

CREATE INDEX IF NOT EXISTS idx_task_offers_user ON task_offers(user_id);
-- Второго выбранного исполнителя не будет даже при двух одновременных «Выбрать».
CREATE UNIQUE INDEX IF NOT EXISTS idx_task_offers_accepted
  ON task_offers(task_id) WHERE status = 'accepted';
```

Миграций в `db/index.js` не нужно: `schema.sql` выполняется при каждом старте, `CREATE … IF
NOT EXISTS` создаст таблицы на боевой базе при первом деплое и дальше ничего не делает.

**Step 3: Реализация** (`backend/src/exchange.js`):

```js
const { abroadWork } = require('./abroad');
const { money } = require('./money');

// Биржа услуг: правила задач и откликов без базы (запросы — в tasksRepo.js).
// Всё «можно или нельзя» решается здесь: сайт и будущее Android-приложение
// получают от роута один и тот же ответ, а тесты проверяют правила без Postgres.

const WORK_FORMATS = ['online', 'offline'];
const MAX_PRICE = 10000000;
const LIMITS = { title: 100, description: 3000, city: 60, address: 200, when: 60, term: 60, comment: 1000 };

const text = (value) => String(value ?? '').trim();

// Цену набирают как на ценнике — «2 000» и «2000» одно и то же.
function toPrice(value) {
  const n = Number(text(value).replace(/\s/g, ''));
  return Number.isInteger(n) && n >= 1 && n <= MAX_PRICE ? n : null;
}

// partial — правка: проверяем только присланные поля, остальные не трогаем.
function validateTask(body, { categories, partial = false }) {
  const errors = [];
  const result = {};
  const given = (key) => !partial || body[key] !== undefined;

  if (given('title')) {
    const v = text(body.title);
    if (!v) errors.push('Напишите, что нужно сделать');
    else if (v.length > LIMITS.title) errors.push(`Название слишком длинное (макс. ${LIMITS.title} символов)`);
    else result.title = v;
  }
  if (given('description')) {
    const v = text(body.description);
    if (!v) errors.push('Опишите задачу подробнее');
    else if (v.length > LIMITS.description) {
      errors.push(`Описание слишком длинное (макс. ${LIMITS.description} символов)`);
    } else result.description = v;
  }
  if (given('category')) {
    if (!categories.includes(body.category)) errors.push('Выберите категорию из списка');
    else result.category = body.category;
  }
  if (given('city')) {
    const v = text(body.city);
    if (!v) errors.push('Укажите город');
    else if (v.length > LIMITS.city) errors.push('Слишком длинное название города');
    else result.city = v;
  }
  if (given('address')) {
    const v = text(body.address);
    if (v.length > LIMITS.address) errors.push(`Адрес слишком длинный (макс. ${LIMITS.address} символов)`);
    else result.address = v || null;
  }
  if (given('work_format')) {
    if (!WORK_FORMATS.includes(body.work_format)) errors.push('Укажите формат работы — онлайн или офлайн');
    else result.work_format = body.work_format;
  }
  if (given('budget')) {
    if (!text(body.budget)) result.budget = null;
    else {
      const n = toPrice(body.budget);
      if (n === null) errors.push('Бюджет — целое число сом, или оставьте поле пустым');
      else result.budget = n;
    }
  }
  if (given('when_text')) {
    const v = text(body.when_text);
    if (v.length > LIMITS.when) errors.push('Срок слишком длинный — хватит пары слов');
    else result.when_text = v || null;
  }

  // Только работа в Кыргызстане — то же правило, что у заказов (см. abroad.js).
  // При правке смотрим то, что пришло: заграница в одном поле — тоже заграница.
  const abroad = abroadWork([result.title, result.description, result.city].filter(Boolean).join('\n'), {
    job: true,
  });
  if (abroad) errors.push(`Шабашка публикует только работу в Кыргызстане, а здесь указано «${abroad}»`);

  return { errors, result };
}

function validateOffer(body = {}) {
  const errors = [];
  const price = toPrice(body.price);
  if (price === null) errors.push('Укажите цену — целое число сом');
  const term = text(body.term);
  if (!term) errors.push('Укажите срок: например, «завтра до обеда»');
  else if (term.length > LIMITS.term) errors.push('Срок слишком длинный — хватит пары слов');
  const comment = text(body.comment);
  if (!comment) errors.push('Напишите, что именно сделаете');
  else if (comment.length > LIMITS.comment) {
    errors.push(`Комментарий слишком длинный (макс. ${LIMITS.comment} символов)`);
  }
  return { errors, result: { price, term, comment } };
}

// Почему с задачей уже ничего не сделать — по её статусу.
const CLOSED = {
  assigned: 'Исполнитель уже выбран',
  done: 'Задача уже выполнена',
  cancelled: 'Задача отменена',
};
const FINAL = ['done', 'cancelled'];

// Почему откликнуться нельзя; null — можно. offer — прежний отклик этого
// человека на эту задачу, если был.
function offerBlocker(task, userId, offer) {
  if (task.user_id === userId) return { status: 400, error: 'Это ваша задача — откликнуться на неё нельзя' };
  if (task.status !== 'open') return { status: 409, error: CLOSED[task.status] };
  // Снятый модератором и отменённый заказчиком отклик правкой не воскресает:
  // иначе «удалить отклик» и «отменить выбор» ничего бы не значили.
  if (offer?.status === 'removed') return { status: 403, error: 'Ваш отклик снял модератор' };
  if (offer?.status === 'dropped') {
    return { status: 403, error: 'Заказчик отменил выбор — откликнуться на эту задачу снова нельзя' };
  }
  return null;
}

// Действия заказчика и статусы, из которых они возможны. error — что сказать,
// если статус не тот, но и не окончательный (выполнена/отменена).
const OWNER_ACTIONS = {
  edit: { from: ['open'], error: 'Задачу можно править, пока исполнитель не выбран' },
  accept: { from: ['open'] },
  unassign: { from: ['assigned'], error: 'Исполнитель ещё не выбран' },
  done: { from: ['assigned'], error: 'Сначала выберите исполнителя' },
  cancel: { from: ['open', 'assigned'] },
};

function ownerBlocker(task, userId, action) {
  if (task.user_id !== userId) return { status: 403, error: 'Это не ваша задача' };
  const rule = OWNER_ACTIONS[action];
  if (rule.from.includes(task.status)) return null;
  const error = FINAL.includes(task.status) ? CLOSED[task.status] : rule.error || CLOSED[task.status];
  return { status: 409, error };
}

function withdrawBlocker(task, offer) {
  if (!offer || offer.status !== 'active') return { status: 404, error: 'Отклика, который можно отозвать, нет' };
  if (task.status !== 'open') return { status: 409, error: CLOSED[task.status] };
  return null;
}

// Что исполнитель видит про свой отклик — одним словом, чтобы сайт и приложение
// показывали одно и то же: waiting — ждёт решения, chosen — выбран, done —
// выполнил, other — выбран другой, cancelled — задачу отменили, withdrawn —
// отозвал сам, dropped — заказчик отменил выбор, removed — снят модератором.
function offerState(offerStatus, taskStatus) {
  if (['withdrawn', 'dropped', 'removed'].includes(offerStatus)) return offerStatus;
  if (taskStatus === 'cancelled') return 'cancelled';
  if (offerStatus === 'accepted') return taskStatus === 'done' ? 'done' : 'chosen';
  return taskStatus === 'open' ? 'waiting' : 'other';
}

// Первое сообщение в переписке после выбора. Уходит от имени заказчика: так у
// исполнителя загорается обычный значок непрочитанного и ответить можно сразу.
function chosenMessage(task, offer) {
  return (
    `Здравствуйте! Выбираю вас исполнителем по задаче «${task.title}»: ` +
    `${money(offer.price)} сом, срок — ${offer.term}. Давайте договоримся о деталях.`
  );
}

     ), offer AS (
       UPDATE task_offers SET status = 'accepted', updated_at = NOW()
       WHERE id = $3 AND task_id IN (SELECT id FROM task) AND status = 'active'
       RETURNING *
     ), assigned AS (
       UPDATE tasks SET status = 'assigned', updated_at = NOW()
       WHERE id IN (SELECT task_id FROM offer)
       RETURNING id
     )
     SELECT * FROM offer`,
    [taskId, ownerId, offerId]
  );
  return rows[0] || null;
}

// Исполнитель пропал — заказчик отменяет выбор, задача снова собирает отклики.
async function unassign(taskId, ownerId) {
  const { rows } = await db.query(
    `WITH task AS (
       UPDATE tasks SET status = 'open', updated_at = NOW()
       WHERE id = $1 AND user_id = $2 AND status = 'assigned'
       RETURNING id
     ), dropped AS (
       UPDATE task_offers SET status = 'dropped', updated_at = NOW()
       WHERE task_id IN (SELECT id FROM task) AND status = 'accepted'
       RETURNING id
     )
     SELECT id FROM task`,
    [taskId, ownerId]
  );
  return rows.length > 0;
}

// Переписка с выбранным исполнителем: ветка одна на пару (задача, исполнитель),
// первое сообщение — от заказчика (см. exchange.chosenMessage).
async function openChat(task, offer, body) {
  const { rows } = await db.query(
    `INSERT INTO conversations (listing_type, listing_id, seeker_id, employer_id)
     VALUES ('task', $1, $2, $3)
     ON CONFLICT (listing_type, listing_id, seeker_id) DO UPDATE SET last_message_at = NOW()
     RETURNING id`,
    [task.id, offer.user_id, task.user_id]
  );
  const conversationId = rows[0].id;
  await db.query('INSERT INTO messages (conversation_id, sender_id, body) VALUES ($1, $2, $3)', [
    conversationId,
    task.user_id,
    body,
  ]);
  return conversationId;
}

// Переписка заказчика с тем, кто сейчас выбран, — для кнопки «Написать».
async function chosenChat(taskId) {
  const { rows } = await db.query(
    `SELECT c.id FROM conversations c
     JOIN task_offers o ON o.task_id = c.listing_id AND o.user_id = c.seeker_id
     WHERE c.listing_type = 'task' AND c.listing_id = $1 AND o.status = 'accepted'`,
    [taskId]
  );
  return rows[0] ? rows[0].id : null;
}

// Снять отклик по жалобе. Если сняли выбранного исполнителя, задача снова
// открыта: иначе она осталась бы «исполнитель выбран» без исполнителя.
async function removeOffer(offerId) {
  const { rows } = await db.query(
    `WITH old AS (
       SELECT id, task_id, status FROM task_offers WHERE id = $1
     ), removed AS (
       UPDATE task_offers SET status = 'removed', updated_at = NOW()
       WHERE id IN (SELECT id FROM old) RETURNING id
     ), reopened AS (
       UPDATE tasks SET status = 'open', updated_at = NOW()
       WHERE id IN (SELECT task_id FROM old WHERE status = 'accepted') AND status = 'assigned'
       RETURNING id
     )
     SELECT (SELECT COUNT(*) FROM removed)::int AS removed, (SELECT COUNT(*) FROM reopened)::int AS reopened`,
    [offerId]
  );
  return rows[0];
}

// Закрыть задачу по жалобе: не удаляем — на неё есть жалоба, и она сама себе
// доказательство (как заказы, см. admin.js).
async function closeTask(taskId) {
  const { rows } = await db.query(
    `UPDATE tasks SET status = 'cancelled', updated_at = NOW()
     WHERE id = $1 AND status IN ('open', 'assigned') RETURNING id`,
    [taskId]
  );
  return rows.length > 0;
}

  done: (task) => repo.setStatus(task.id, task.user_id, ['assigned'], 'done'),
  unassign: (task) => repo.unassign(task.id, task.user_id),
};

for (const [action, step] of Object.entries(OWNER_STEPS)) {
  router.post(
    `/:id/${action}`,
    requireAuth,
    asyncHandler(async (req, res) => {
      const task = await loadTask(req, res);
      if (!task) return;
      const blocker = exchange.ownerBlocker(task, req.user.id, action);
      if (blocker) return refuse(res, blocker);
      if (!(await step(task))) {
        return res.status(409).json({ error: 'Статус задачи уже изменился — обновите страницу' });
      }
      invalidate('home:');
      res.json({ task: await repo.get(task.id) });
    })
  );
}

router.get(
  '/:id/offers',
  requireAuth,
  asyncHandler(async (req, res) => {
    const task = await loadTask(req, res);
    if (!task) return;
    if (task.user_id !== req.user.id) return res.status(403).json({ error: 'Отклики видит только автор задачи' });
    res.json({ offers: await repo.offersForOwner(task.id) });
  })
);

// Откликнуться или поправить свой отклик — один адрес на оба случая.
router.post(
  '/:id/offers',
  requireAuth,
  offerLimiter,
  asyncHandler(async (req, res) => {
    const task = await loadTask(req, res);
    if (!task) return;
    const blocker = exchange.offerBlocker(task, req.user.id, await repo.offerOf(task.id, req.user.id));
    if (blocker) return refuse(res, blocker);

    const { errors, result } = exchange.validateOffer(req.body || {});
    if (errors.length) return res.status(400).json({ error: errors[0] });
    const offer = await repo.saveOffer(task.id, req.user.id, result);
    if (!offer) return res.status(409).json({ error: 'Задача уже не принимает отклики' });
    res.status(201).json({ offer: withState(offer, 'open') });
  })
);

router.post(
  '/:id/offers/withdraw',
  requireAuth,
  asyncHandler(async (req, res) => {
    const task = await loadTask(req, res);
    if (!task) return;
    const blocker = exchange.withdrawBlocker(task, await repo.offerOf(task.id, req.user.id));
    if (blocker) return refuse(res, blocker);
    const offer = await repo.withdrawOffer(task.id, req.user.id);
    if (!offer) return res.status(409).json({ error: 'Исполнитель уже выбран' });
    res.json({ offer: withState(offer, task.status) });
  })
);

// Выбрать исполнителя: задача закрывается для откликов, с выбранным открывается
// переписка — первое сообщение уходит от имени заказчика.
router.post(
  '/:id/offers/:offerId/accept',
  requireAuth,
  asyncHandler(async (req, res) => {
    const task = await loadTask(req, res);
    if (!task) return;
    const blocker = exchange.ownerBlocker(task, req.user.id, 'accept');
    if (blocker) return refuse(res, blocker);

    const offerId = toId(req.params.offerId);
    const offer = offerId && (await repo.accept(task.id, req.user.id, offerId));
    if (!offer) return res.status(409).json({ error: 'Этот отклик уже нельзя выбрать — обновите страницу' });

    const conversationId = await repo.openChat(task, offer, exchange.chosenMessage(task, offer));
    invalidate('home:');
    res.json({ task: await repo.get(task.id), offer, conversation_id: conversationId });
  })
);

// Жалоба на задачу — от всех и без аккаунта, как у заказов.
router.post(
  '/:id/report',
  reportLimiter,
  asyncHandler(async (req, res) => {
    const reason = String(req.body?.reason || '').trim();
    if (!reason) return res.status(400).json({ error: 'Укажите причину жалобы' });
    const id = toId(req.params.id);
    const reportId = id && (await reportsRepo.create({ listingType: 'task', listingId: id, reason }));
    if (!reportId) return res.status(404).json(NOT_FOUND);
    res.status(201).json({ ok: true });
  })
);

// Жалоба на отклик — только от заказчика: отклики целиком видит лишь он, а
// просьбы о предоплате и спам приходят именно туда.
router.post(
  '/:id/offers/:offerId/report',
  requireAuth,
  reportLimiter,
  asyncHandler(async (req, res) => {
    const task = await loadTask(req, res);
    if (!task) return;
    if (task.user_id !== req.user.id) {
      return res.status(403).json({ error: 'Пожаловаться на отклик может только автор задачи' });
    }
    const reason = String(req.body?.reason || '').trim();
    if (!reason) return res.status(400).json({ error: 'Укажите причину жалобы' });
    const offerId = toId(req.params.offerId);
    const offer = offerId && (await repo.offerById(offerId));
    if (!offer || offer.task_id !== task.id) return res.status(404).json({ error: 'Отклик не найден' });

    await reportsRepo.create({ listingType: 'offer', listingId: offer.id, reason });
    res.status(201).json({ ok: true });
  })
);

module.exports = router;
```
