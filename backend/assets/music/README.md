# Фонотека для роликов

Сюда кладём фоновые треки (`.mp3`, `.m4a`, `.aac`, `.ogg`, `.wav`). Для каждого
ролика бот берёт **случайный** файл из этой папки, приглушает его и уводит
в тишину к концовке. Если папка пустая — ролик уходит с тишиной, публикация
не ломается.

Хватит 3–5 треков по 15–30 секунд: ролик длится 9 секунд, короткий трек
зацикливается автоматически.

## Почему не музыка из Instagram

Библиотеку Instagram (тренды, оригинальные звуки) через API подложить нельзя:
трек выбирают только вручную в приложении при публикации. Ролик, опубликованный
по API, уходит со своей дорожкой, и заменить её потом не получится.

## Где брать треки

Нужна лицензия, разрешающая коммерческое использование, — Instagram снимает
ролики за чужую музыку. Подойдут:

- [Pixabay Music](https://pixabay.com/music/) — без атрибуции
- [Free Music Archive](https://freemusicarchive.org/) — смотреть лицензию CC
- [YouTube Audio Library](https://studio.youtube.com/) — раздел «Звуки»

Файлы коммитим в репозиторий: на Render диск эфемерный, скачивать их неоткуда.
