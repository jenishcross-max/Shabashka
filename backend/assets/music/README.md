# Фонотека для роликов

Здесь лежат фоновые треки. Для каждого ролика бот берёт **случайный** файл,
приглушает его и уводит в тишину к концовке. Если брать нечего — ролик уходит
с тишиной, публикация не ломается.

Сейчас в папке 10 треков Kevin MacLeod ([incompetech.com](https://incompetech.com/))
под лицензией **CC BY 4.0**: спокойные и бодрые инструменталы без вокала, чтобы
не спорить с текстом на кадре. Каждый — 20-секундный фрагмент, обрезанный
из оригинала и выровненный по громкости (−16 LUFS), 96 kbit/s. Целые треки
по 5–12 МБ в репозитории не нужны: ролик длится 9 секунд.

## credits.json — обязателен

Файл без записи в `credits.json` бот **не возьмёт**, даже если тот лежит рядом
с остальными. Это не придирка: CC BY разрешает использовать музыку только при
указании автора, и строка из `credits.json` уходит в описание поста в Instagram.
Трек без известного автора — это ролик, который можно снять по жалобе, поэтому
такой файл проще проигнорировать.

Добавляя трек, добавь и запись:

```json
"имя-файла.mp3": { "title": "Название", "author": "Автор", "source": "откуда" }
```

В подпись это превращается в строку вида:

```
♪ Carefree — Kevin MacLeod (incompetech.com), фрагмент
Лицензия CC BY 4.0 — creativecommons.org/licenses/by/4.0
```

Слово «фрагмент» тоже по лицензии: она требует отмечать, что запись изменена,
а мы режем и нормализуем. Если положишь трек целиком и без обработки — убери
это слово из `music.js`.

## Как нарезать новый трек

```bash
ffmpeg -ss 30 -t 20 -i original.mp3 -af "loudnorm=I=-16:TP=-2:LRA=11,afade=t=in:st=0:d=0.15,afade=t=out:st=19.6:d=0.4" -c:a libmp3lame -b:a 96k -ac 2 -ar 44100 new-track.mp3
```

Отступ в 30 секунд — чтобы миновать вступление: в ролик попадает самое начало
файла, и оно должно звучать уже развёрнуто, а не набирать громкость.

## Почему не музыка из Instagram

Библиотеку Instagram (тренды, оригинальные звуки) через API подложить нельзя:
трек выбирают только вручную в приложении при публикации. Ролик, опубликованный
по API, уходит со своей дорожкой, и заменить её потом не получится. Нужен
трендовый звук — публикуй ролик руками: без токена бот просто присылает mp4
в чат.

## Где брать ещё

Нужна лицензия, разрешающая коммерческое использование, — Instagram снимает
ролики за чужую музыку. Подойдут:

- [Pixabay Music](https://pixabay.com/music/) — без атрибуции
- [Free Music Archive](https://freemusicarchive.org/) — смотреть лицензию CC
- [YouTube Audio Library](https://studio.youtube.com/) — раздел «Звуки»

Файлы коммитим в репозиторий: на Render диск эфемерный, скачивать их неоткуда.
